# Cursor Landing Page Clone

A pixel-perfect clone of the Cursor AI editor landing page, built with vanilla HTML, CSS, and JavaScript using Vite as the build tool.

## Live Link
[Cursor clone](https://cursor-ui-clone-nycxkm86k-aryan-561s-projects.vercel.app/)
## 🚀 Project Overview

This project is a faithful recreation of the Cursor landing page, showcasing modern web development practices and responsive design. Cursor is an AI-powered code editor, and this clone demonstrates the ability to replicate professional landing pages with attention to detail.

## ✨ Features

- **Modern UI/UX**: Clean and professional interface matching the original Cursor design
- **Hero Section**: Eye-catching hero section with call-to-action buttons
- **Company Showcase**: Display of trusted companies and professional developers
- **Feature Sections**: Multiple sections highlighting key features and capabilities
- **Fast Performance**: Built with Vite for lightning-fast development and optimized builds

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with custom properties and flexbox/grid layouts
- **JavaScript**: Interactive elements and functionality
- **Vite**: Next-generation frontend build tool
- **Font Awesome**: Icon library for UI elements

## 🚦 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aryan-561/cursor-ui-clone.git
   cd cursor-ui-clone
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173` (or the port shown in terminal)

## 📜 Available Scripts

- `npm run dev` - Starts the development server with hot module replacement
- `npm run build` - Creates an optimized production build
- `npm run preview` - Preview the production build locally

## 🎨 Customization

You can customize the landing page by:

- Modifying the [style.css](src/style.css) file for styling changes
- Updating the [index.html](index.html) file for content and structure
- Replacing images in the `public/` directory with your own assets

## 🌐 Deployment

To deploy this project:

1. Build the project:
   ```bash
   npm run build
   ```

2. The optimized files will be in the `dist/` folder

3. Deploy the `dist/` folder to your hosting service (Vercel, Netlify, GitHub Pages, etc.)
